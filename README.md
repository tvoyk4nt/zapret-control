# Zapret Control

**Zapret Control** — настольное приложение для Windows с графическим интерфейсом, предназначенное для просмотра состояния и диагностической информации Flowseal / Zapret.

Интерфейс помогает просматривать сведения о локальной установке, доступных стратегиях, журнале событий и резервных копиях, а также проверять информацию о выпусках приложения и Flowseal.

## Возможности

- Просмотр состояния служб Windows, связанных с установленной конфигурацией.
- Просмотр списка обнаруженных стратегий и сведений о текущей стратегии.
- Определение установленной версии Flowseal.
- Просмотр информации о новых выпусках Flowseal и Zapret Control.
- Просмотр журнала событий, фильтрация записей и экспорт в TXT.
- Просмотр и управление резервными копиями.
- Настройки приложения, выбор расположения установки Flowseal и светлая / тёмная тема.

> Состояние служб Windows само по себе не подтверждает доступность сайтов или работоспособность сетевого подключения.

## Системные требования

- Windows 10 или Windows 11.
- 64-разрядная система (x64).
- Для функций, связанных с Flowseal, требуется отдельная локальная установка Flowseal / Zapret.

## Установка

1. Откройте страницу [Releases](https://github.com/tvoyk4nt/zapret-control/releases).
2. Выберите нужный выпуск.
3. Скачайте один из установщиков Windows x64:
   - **NSIS** — файл с окончанием `.exe`.
   - **MSI** — файл с окончанием `.msi`.
4. Запустите установщик и следуйте его инструкциям.

Если в разделе Releases пока нет опубликованных выпусков, установщики ещё не опубликованы.

## Обновления

Приложение может проверять наличие новых выпусков и открывать страницу релиза. Загрузка и установка обновлений Flowseal выполняются пользователем самостоятельно с официальной страницы проекта.

Автоматическое обновление Zapret Control через встроенный updater может быть недоступно в отдельных сборках, пока не настроена подпись обновлений.

## Сборка из исходного кода

### Необходимые инструменты

- Node.js и npm.
- Rust и Cargo.
- Инструменты сборки Tauri для Windows.

### Команды

Установить зависимости:

```powershell
npm ci
```

Запустить приложение в режиме разработки:

```powershell
npm run tauri dev
```

Собрать frontend:

```powershell
npm run build
```

Собрать приложение и установщики:

```powershell
npm run tauri build
```

Готовые артефакты Tauri обычно находятся в:

```text
src-tauri/target/release/bundle/
```

## Важная информация

- Zapret Control — графическая оболочка и диагностический инструмент; это не отдельная реализация Flowseal / Zapret.
- Flowseal / Zapret не входит в установщик Zapret Control и устанавливается отдельно.
- Проверяйте загружаемые файлы и инструкции на официальных страницах соответствующих проектов.
- Проект не связан официально с авторами Flowseal или Tauri.
